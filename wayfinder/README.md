# Wayfinder

The wayfinder map for this repo lives on **GitHub Issues**, per [`docs/agents/issue-tracker.md`](../docs/agents/issue-tracker.md):

- **Map**: [Map: Back pain, posture, and getting strong (#1)](https://github.com/AdrianZaplata/Health/issues/1) — labelled `wayfinder:map`, with tickets as sub-issues.
- **Frontier**: open, unblocked, unassigned sub-issues of the map. Blocking is a `Blocked by: #n` line at the top of a ticket body (native issue dependencies aren't wired from this environment).
- **Assets**: research findings live in [`research/`](./research/) here, linked from their tickets.

> History note: the map was first charted as local markdown in this directory (before the tracker doc existed on `main`) and then migrated to GitHub Issues. The original ticket files are in git history at commit `7de5f60`.
